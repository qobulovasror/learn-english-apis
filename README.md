# Learning English API
There are several APIs for making learning english apps

## Requirements
1. Node.js
2. Typescript
3. npm (Node Package Manager)
4. Express

## Installation

1. Clone this repository to your local machine:
  ```bash
    git clone https://github.com/qobulovasror/learn-english-apis.git
  ```
2. Navigate to the project directory:
   ```bash
    cd learn-english-apis
   ```
4. Install server dependencies:
   ```bash
    npm install
   ```
5. Add .env file for environments then add defult port:
   PORT =5000  
6. Start the development server:
   ```bash
    npm run dev
   ```
7. Access the application through your web browser at http://localhost:5000.
